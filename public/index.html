    The final score, bought and checked

    1. Read the proposal

      Gainsay listens to UMA's managed oracle on Polygon and maps each proposal to its Polymarket market. Requests from other platforms using the same oracle are refused, not guessed.

    2. Buy the final score

      It pays a Telegraph provider for the result, using each provider's own parameters. Providers that only repeat a prediction market's own answer are excluded.

    3. Reject the wrong game

      An answer counts only if it names the same teams and a kickoff within three hours of the market's. In testing, paid answers came back about other games with every field marked ok. Gainsay rejects those.

    4. Settle it by arithmetic

      Winners, totals and spreads are computed from the score, not read from a model. A push, a draw or disagreeing sources come back as contested.

    Not covered yet

    • Player props, quarters and halves need box scores that no Telegraph provider serves yet
    • Most leagues have one working source today, and every verdict says so
    • Gainsay never proposes, disputes or posts a bond. You decide
    • Evidence is paid with test USDC on Ethereum Sepolia. UMA proposals are real Polygon mainnet data
